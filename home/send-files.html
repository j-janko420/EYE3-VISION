Send a big file

Chat attachments are limited to roughly 30 MB per file, so a 39 MB file is refused. Use one of these three ways. The first one almost always works.

Best1. Zip it first

Playlists and lists are plain text, and text shrinks a lot. A 39 MB .m3u usually becomes 3 to 6 MB as a zip.

  1. Windows: right-click the file → Send to → Compressed (zipped) folder.
  2. Mac: right-click the file → Compress.
  3. iPhone: Files app → press and hold the file → Compress.
  4. Attach the new .zip in the chat.

2. Still too big? Split it into parts

Make several parts, each under 25 MB, and attach them all in the same message.

  1. Install the free 7-Zip (Windows).
  2. Right-click the file → 7-Zip → Add to archive…
  3. Archive format: zip. In Split to volumes, bytes type 20M. Press OK.
  4. You get file.zip.001, file.zip.002 and so on. Attach every part.

On Mac or Linux, in Terminal: zip -s 20m -r parts.zip yourfile and attach every parts.z01, parts.z02 … plus parts.zip.

3. Send only the part I need

For a problem with a playlist, the first lines are enough. Open the file in Notepad and copy the first 50 lines into a message. For a list of channels, 20 lines from the middle too.

Before you send

Remove passwords first. Anything you put in a public place can be read by others. In a playlist or settings file, replace usernames, passwords, MAC addresses and token links with XXXX. The chat itself is private, but a public web page or repository is not.
