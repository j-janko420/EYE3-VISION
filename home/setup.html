i3DESIGN

Make an always-on EYE3 box

A screen can't run software by itself — a small device plugged into the TV's HDMI does. Set one up once with EYE3 Home as an app, leave it behind the TV, and the TV turns on straight into EYE3, online, with no laptop needed each time. Pick what you have.

EYE3 Home: https://j-janko420.github.io/EYE3-VISION/home/

One-time install kit PC, mini-PC, Raspberry Pi, Mac

Install once, from a USB stick or by download. After that the computer behind the TV starts EYE3 by itself, keeps EYE3 Link running, fixes connection problems and updates itself. The TV itself (for example a Philips Saphi) cannot install software from a USB stick, so this goes on the box plugged into its HDMI port.

  1. Download the kit for your system from the release page: EYE3-Box-Windows.zip, EYE3-Box-Linux.zip or EYE3-Box-Mac.zip. Unzip it onto a USB stick (or anywhere).
  2. Put your own playlists (.m3u, .m3u8, .txt) into the playlists folder first, if you like. They show up in Live TV by themselves; adult groups only inside the hidden Explicit section.
  3. Windows: double-click install.bat. Linux, Raspberry Pi, Mac: open a terminal in the folder and run sh install.sh.
  4. Reboot or sign in again: EYE3 Link and EYE3 Home open fullscreen. The Agent chip on the top bar shows what the agent did.

Try it first without changing anything: sh install.sh --dry-run (Windows: install.bat -DryRun). The program is checked against its published SHA-256 before it is used, and it is not code-signed, so your system may warn. EYE3 does not include a VPN or any channels.

Spare Android phone cheapest

A phone you no longer use, plus a USB-C-to-HDMI adapter (about $8). This becomes your EYE3 stick.

  1. Open Chrome on the phone and go to the EYE3 Home link above.
  2. Menu (⋮) → Add to Home screen / Install app. EYE3 Home installs as a fullscreen app with the i3 icon.
  3. Open the EYE3 app once and press the Settings tile → it's already fullscreen.
  4. In the phone's settings: Display → Screen timeout → Never (or "stay awake while charging" in Developer options), and keep it on the charger.
  5. Plug the phone into the TV with the USB-C-to-HDMI adapter, pick that HDMI input on the TV, and tuck the phone behind the TV.
  6. For a true "kiosk" that relaunches on boot, install Fully Kiosk Browser (free), set Start URL to the EYE3 Home link, and enable "Launch on boot" + "Keep screen on".

Raspberry Pi tidy & permanent

A Raspberry Pi (3, 4, 5, or Zero 2 W) with Raspberry Pi OS. It boots straight into EYE3 Home in Chromium kiosk mode.

  1. Install Chromium: sudo apt update && sudo apt install -y chromium-browser unclutter
  2. Create ~/.config/autostart/eye3.desktop with:
[Desktop Entry]
Type=Application
Name=EYE3 Home
Exec=chromium-browser --kiosk --noerrdialogs --disable-infobars \
  --autoplay-policy=no-user-gesture-required \
  https://j-janko420.github.io/EYE3-VISION/home/?app=1
X-GNOME-Autostart-enabled=true

Then disable screen blanking (Preferences → Raspberry Pi Configuration → Display, Screen Blanking Off) and reboot. The Pi now powers on into EYE3 Home.

Old laptop or mini-PC reuse what you have

Any old laptop or a cheap mini-PC left behind the TV, connected by HDMI. Set it to open EYE3 Home fullscreen on start.

  1. Windows: make a shortcut with target
    chrome.exe --kiosk --app=https://j-janko420.github.io/EYE3-VISION/home/?app=1
    and put it in the Startup folder (Win+R → shell:startup).
  2. Mac: open the EYE3 Home link in Chrome, ⋮ → Cast, save and share → Install page as app, then add that app to System Settings → General → Login Items.
  3. Linux: use the same Chromium kiosk command as the Raspberry Pi above in your autostart.
  4. Set the laptop to never sleep while plugged in, and to turn on the screen / resume on power. Close the lid only if "do nothing on lid close" is set.

A bought Android TV stick simplest, small cost

A Google TV Streamer, Chromecast with Google TV, or a Fire TV stick (about $30–60). It's Android, so it also runs SmartTube, IPTV apps and more.

  1. Plug it into HDMI and finish its setup.
  2. Install a browser (e.g. TV Bro or Chrome) and open the EYE3 Home link, or install the EYE3 Home app from the browser.
  3. Optionally set it as the launcher with the CleanYourTV approach for a fully EYE3-branded home screen.

Whichever you choose: the device stays plugged into HDMI and online; the Philips TV is untouched and just displays it. Unplug any time to go back to normal TV.
