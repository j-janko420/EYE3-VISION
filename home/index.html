Checking EYE3 Link…

Your provider cannot be read straight from a web page, so a small helper runs on this computer.
  1. Install Python 3 if you do not have it (python.org).
  2. Download eye3-link.py
  3. Run python3 eye3-link.py (Windows: py eye3-link.py) and leave that window open.

No Python? Download the ready-to-run program for Windows, Mac (Apple chip) or Linux, then just open it. It is not code-signed, so your system may warn you.
