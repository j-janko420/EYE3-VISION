Your playlists folder
=====================

Put YOUR OWN playlist files here: .m3u, .m3u8 or .txt (a plain list of links works too).
EYE3 Link reads this folder by itself, and EYE3 Home shows every file as its own list in Live TV.

 * Nothing is uploaded. The files stay on this computer.
 * Adult groups are never shown in the normal lists. They appear only in the hidden Explicit (18+)
   section, after you unlock it (double-click the eye logo, or Shift+X).
 * EYE3 does not provide channels. Use lists you are allowed to watch.
 * Add, change or remove a file at any time: Home notices within half a minute.
 * Copy more files in from a USB stick whenever you like; you do not need to run the installer again.
